# Melo storefront

Отдельная адаптивная информационная витрина Melo на HTML, CSS и JavaScript.

Откройте `index.html` в браузере для просмотра. Переключатель в правом верхнем углу меняет весь текст страницы на русский, армянский или английский; выбранный язык сохраняется в браузере. Папку `music_project_storefront` можно развернуть отдельно как статический сайт. Перед публикацией проверьте ссылку на приложение Melo в `index.html`.
